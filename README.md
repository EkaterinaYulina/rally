# Ралли — визуальная новелла (пролог и главы 2–6)

HTML5/JS-новелла про ралли для Яндекс Игр. Сборка плоская, без бандлера: открывается через любой статический сервер.

## Запуск

    python3 -m http.server 8765

и открыть http://localhost:8765

## Структура

- `index.html`, `style.css`, `fonts.css` — разметка и стили
- `js/story.js` — сценарий (плоский формат битов), главы 1–6 (четыре концовки)
- `js/main.js` — движок сцен, маршрутный лист, протокол этапа
- `js/rally-model.js`, `js/rally-data.js` — модель времени и очков (данные сезона v6)
- `assets/` — фоны; `fonts/` — шрифты

## Обложка и главы

Первый экран — обложка («Продолжить» / «Новая игра» / «Главы»). Кнопка в шапке (клавиша O) возвращает из игры на обложку, место в сюжете сохраняется. Экран «Главы» открывается с обложки и с экрана концовки.
Глава открывается, когда игрок до неё дошёл; на входе в главу запоминаются его решения (`put.prog.v1`), поэтому глава из оглавления стартует с прежними последствиями. «Новая игра» стирает место в сюжете, но не открытые главы.

## Реклама и сборка для Яндекс Игр

- `js/ads.js` — единственное место, где игра говорит с SDK. На Яндексе: полноэкранная реклама между главами (со 2-й), пауза музыки, `LoadingAPI.ready()`. Вне Яндекса SDK нет, игра идёт без рекламы.
- `?adtest` — проверка без Яндекса: вместо рекламы серая плашка на 2,5 с, музыка на паузе, ввод заблокирован.
- Sticky-баннер включается в черновике игры на Яндексе, кодом не вызывается.
- `bash tools/build-yandex.sh` — собирает `rally-yandex.zip` для загрузки в черновик: подключён `/sdk.js`, нет кнопки «Назад», отладочных параметров URL и шага назад по клавише ←. Рабочая версия в main остаётся с техническими кнопками (для GitHub Pages).

## Сборка для ВКонтакте (VK Mini Apps)

- `js/ads-vk.js` — аналог `ads.js` для VK Bridge: `VKWebAppInit`, полноэкранная реклама между главами (со 2-й), пауза при сворачивании приложения. Интерфейс `VN_ADS` тот же, `main.js` не менялся.
- `bash tools/build-vk.sh` — собирает `rally-vk.zip`: VK Bridge лежит в архиве (`vendor/`), нет кнопок «Назад» и «Маршрутный лист», отладочных параметров URL и шага назад по клавише ←. Рабочая версия в main остаётся с техническими кнопками.

## Параметры URL для отладки

- `?s=<id сцены>` — перейти к сцене
- `?f=k14:A,…` — задать флаги выборов
- `?end` — экран концовки (ветка — по `?f=`: например `?end&f=k63:B,k66:B` — Финал В)
- `?fresh` — сбросить сохранение
- `?static` — без анимаций
- `?nocover` — пропустить обложку (любой из `?s`, `?b`, `?f`, `?k`, `?end` тоже её пропускает)

В консоли доступен `window.__vn` (jump, flags, snaps, derived, stats, lines, opts, protocol, ending).

## Сборки для VK

- `bash tools/build-vk.sh` — версия для VK Mini Apps: VK Bridge, реклама между главами, прогресс игрока в хранилище ВК (`js/vk-boot.js` подтягивает его до старта игры и дублирует записи; если ВК не отвечает 2,5 с, игра идёт на localStorage). Результат — `rally-vk.zip`.
- `bash tools/build-vkplay.sh` — версия для VK Play (iframe): без технических кнопок и без SDK, реклама не показывается. Результат — `rally-vkplay.zip`.
- Обе сборки лежат на GitHub Pages в репозитории rally-vk: корень — VK Play, `mini/` — мини-приложение.
