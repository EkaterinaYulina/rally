# Модель расчётов «Пути» (v6)

- `rally_season_data.json` — калиброванное поле сезона (seed 20260926): этапы, очки, константы модели, экипажи и их результаты. Источник для `js/rally-data.js`, вручную не править
- `rally_tables_calibration.py` — перебор всех 1 399 680 комбинаций выборов: баланс концовок, влияние выборов, места по этапам. Запуск: `python3 rally_tables_calibration.py` (только стандартная библиотека)

Движок (`js/rally-model.js`, `js/main.js`) сверен с этим скриптом полным перебором: концовка, место на финале и место в итоговом зачёте совпали во всех 1 399 680 комбинациях
